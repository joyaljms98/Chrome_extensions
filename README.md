**A modern, feature-rich bookmark manager to save, categorize, and annotate your digital world.**

LinkNest is a powerful browser extension designed to replace the native bookmarking experience with a suite of advanced tools. It allows you to not only save links but to categorize them, add detailed notes with Markdown support, and manage your collection with an intuitive, customizable interface. Say goodbye to bookmark chaos and hello to organized, efficient Browse.

## Key Features

LinkNest is packed with features designed for power users who demand organization and efficiency.

### Organization & Management

  * **Unlimited Categories**: Create distinct categories for different projects, topics, or interests.
  * **Drag & Drop Reordering**: Manually reorder sub-links within a domain and parent website links within a category to perfectly organize your lists.
  * **Advanced Sorting**: Automatically sort categories and links by Name (A-Z, Z-A), Date Created (Newest/Oldest), or Date Modified (Newest/Oldest).
  * **Multi-Select Operations**: Effortlessly select multiple links at once to perform bulk actions like **Move** to another category or **Delete**.
  * **Editable Link Titles**: Double-click any link's title to edit it on the fly, making your bookmarks more descriptive and searchable.
  * **"All Links" View**: A dedicated view to see and sort every single bookmark from all categories in one place.

### Notes & Annotation

  * **Markdown Notes**: Add detailed notes to any link using Markdown for rich text formatting (headings, lists, bold, italics).
  * **Live Markdown Preview**: Toggle between the raw editor and a live preview to see your formatted notes instantly.
  * **Timestamp Information**: Hover over the info icon (`i`) on any link to see its creation and last modified timestamps.

### Powerful Search

  * **Quick Popup Search**: Use the search tab directly in the extension popup to quickly find links by title, URL, or notes without opening the full manager.
  * **Full Manager Search**: A comprehensive search bar in the manager searches across your entire collection.
  * **Contextual Results**: Search results show the link's title, notes snippets, and its location (Category / Domain), with an option to jump directly to its original place.

### Customization & UI

  * **Three Themes**: Choose between **Light**, a modern **Dark** (blue-themed), and an OLED-friendly **Black** mode. Your preference is saved automatically.
  * **Flexible & Resizable Layout**: The UI panels are fully adjustable. Drag the borders to resize the category, links, and notes panels to fit your workflow.
  * **Collapsible Side Menu**: Hide the category panel with a smooth transition to maximize your viewing area for links and notes.
  * **Modern Aesthetics**: A clean, modern UI with a redesigned search bar, button-style "All Links" category, and smooth animations.

### Data Management

  * **Backup & Restore**: Easily back up your entire LinkNest database (bookmarks, notes, and settings) to a JSON file. Restore your data by either merging it with existing data or overwriting it completely.

## Installation

1.  **(Recommended)** Install from the [Chrome Web Store](https://chrome.google.com/webstore/) (Link to be added).
2.  **Manual Installation**:
      * Download the latest release `.zip` file from the [GitHub Releases](https://www.google.com/search?q=https://github.com/joyal-james) page.
      * Unzip the file.
      * Open Chrome and navigate to `chrome://extensions`.
      * Enable **Developer mode** using the toggle in the top-right corner.
      * Click the **"Load unpacked"** button and select the unzipped extension folder.

## How to Use

  * **Saving a Link**: Click the LinkNest icon in your toolbar. The page title will be pre-filled (you can edit it). Select a category or create a new one, add optional notes, and click "Add to LinkNest".
  * **Managing Links**: Click the "Open Full Manager" button from the popup. Here you can create/delete categories, sort links, and edit notes.
  * **Reordering**: In the manager, simply click and drag any link or parent domain to a new position within its category.
  * **Searching**: Use the "Search" tab in the popup for quick finds or the main search bar in the manager for a full database search.
  * **Customizing**: Use the "Toggle Theme" button in the manager's header to cycle through themes. Drag the borders between panels to resize them.
